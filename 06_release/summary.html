06단계 · 실행 확인 및 문서 요약

상태: 완료 · 2026-10-16
마지막 단계로, 앱을 실제 사용하는 방식 그대로 run_app.cmd로 실행해 보고 사용 설명서(README)를 작성했습니다. 앱은 이 PC 안에서만 접속되는 것을 확인했습니다. 아무것도 없는 새 가상환경에 설치 파일 목록만으로 다시 설치해 테스트도 돌려 보았습니다. 다른 PC나 나중에 다시 설치할 때도 같은 결과가 나오는지 확인하기 위해서입니다. 이 과정에서 실행 파일과 설치 안내의 작은 문제 2가지를 고쳤습니다. 이제 MVP가 완성되었습니다. 매일 run_app.cmd를 실행해 Day 1부터 공부하면 됩니다.

1. 매일 사용하는 방법

  1. 앱 켜기프로젝트 폴더의 run_app.cmd를 더블클릭합니다(또는 PowerShell에서 아래 명령). 몇 초 뒤 브라우저가 열립니다. 
    cd C:\Users\jiwoo\python_train
.\run_app.cmd
  2. 오늘의 수업대시보드에서 "학습 시작" → 다섯 단계를 순서대로 진행합니다.
  3. 문제 풀기실행으로 시험해 보고, 채점으로 확인합니다. 막히면 힌트를 하나씩 엽니다.
  4. 완료필수 문제를 모두 통과하고 정리 퀴즈를 내면 다음 Day가 열립니다.
  5. 끄기실행 창을 닫습니다. 기록은 자동 저장됩니다.

2. 실제 실행 확인 결과

확인 항목결과
run_app.cmd를 다른 폴더(홈 폴더)에서 불러도 실행됨확인
접속 주소가 이 PC 전용(127.0.0.1:8501)뿐이고, 네트워크·외부 주소는 열리지 않음확인
브라우저 자동 열림, 실제 학습 기록 파일로 대시보드 표시 (Day 1 열림, Day 2~7 잠김)확인

3. 이번 단계에서 고친 것

문제수정
창 없이 실행되면 브라우저 열기 전 대기 명령(timeout)이 실패해서, 서버가 준비되기 전에 브라우저가 열릴 수 있었음어디서나 동작하는 대기 방식(ping)으로 교체. 4초 대기 확인
설치 경로가 매우 길면 Windows 경로 길이 제한(260자) 때문에 Streamlit 설치가 실패함README "문제 해결"에 원인과 해결 방법 추가 (현재 프로젝트 경로는 문제없음)
홈 폴더에서 pytest를 실행하면 다른 가상환경이 잡혀 "No module named pytest"가 남README 맨 앞에 "프로젝트 폴더에서 실행" 안내와 문제 해결 항목 추가

5. 확인이 필요한 점

실제 학습 기록: 실행 확인 중 열린 브라우저에서 Day 1이 "진행 중"으로 바뀌었습니다(수업 화면을 연 기록 3건). 직접 열어 보신 것으로 보이며, 기록은 그대로 두었습니다.
에디터 자동 들여쓰기: for ...: 다음 줄에서 Enter를 칠 때 자동 들여쓰기가 되는지 직접 타이핑으로 한 번 확인해 주세요. 확인하려던 중 브라우저 창이 닫혀서 끝까지 보지 못했습니다.
git: 현재 git 저장소의 루트가 홈 폴더(C:\Users\jiwoo)입니다. 이 프로젝트만 따로 버전 관리하려면 별도 저장소가 필요합니다. 아직 커밋은 하지 않았습니다.
