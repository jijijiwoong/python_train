5. How Claude Code worked

작업 순서

  1. 기존 형식 읽기다른 세션의 요청을 받고 스키마 문서, Day 6·7 수업 파일, 검증기, 채점기의 값 비교 방식, 기존 테스트를 읽었습니다. 형식과 검사 규칙을 그대로 따르기 위해서입니다.
  2. 주제 배치2주차 주제 "리스트와 튜플"을 6일 + 복습 1일로 나눴습니다.
  3. 수업 파일 생성임시 폴더의 생성 스크립트로 JSON 7개를 만들었습니다. 테스트 기대값은 손으로 계산해 넣었습니다.
  4. 커리큘럼 등록curriculum.json에 개념 태그 8개와 Day 8~14를 추가했습니다.
  5. 1차 검증경고 0건, 14개 Day 자기 검증 모두 통과 (첫 시도).
  6. 테스트 확장 → 오류 → 수정테스트 파일을 셸 명령으로 고치다가 \n이 실제 줄바꿈으로 바뀌어 문법 오류가 났습니다. 같은 수정을 스크립트 파일로 다시 적용해 해결했습니다.
  7. 전체 테스트173개 모두 통과.
  8. 문서 갱신README와 스키마 문서의 "Day 1~7" 표현을 현재 상태로 바꿨습니다.
  9. 기록새 폴더를 만들어도 되는지 확인받은 뒤 이 폴더와 기록 파일을 만들고 index.html을 갱신했습니다.

결정고려한 다른 방법선택한 이유

리스트 컴프리헨션은 쓰지 않음Day 10에 맛보기로 넣기커리큘럼상 7주차 주제. 지금은 반복문 + append 패턴을 익히는 것이 우선
Day 13·14에 선택 도전 문제 1개씩필수 코딩 2개Day 7과 같은 이유: 4분 안에 필수 코딩 2개는 많음
