02단계 · 핵심 엔진 요약

상태: 완료 · 2026-10-16
눈에 보이는 화면 뒤에서 일하는 엔진을 만들었습니다. 엔진은 내가 쓴 코드를 실행하고, 정답인지 채점하고, 모든 학습 기록을 PC 안의 데이터베이스에 저장합니다. 코드는 앱과 분리된 별도 프로그램에서 실행됩니다. 그래서 무한 루프나 엄청난 양의 출력을 만들어도 앱은 멈추지 않습니다. 또 문제를 실제로 풀어야만 수업이 완료되도록 규칙을 넣었습니다. 필요한 프로그램(Streamlit, pytest)은 이 프로젝트 전용 가상환경에 설치했습니다. 자동 테스트 87개를 만들어 모두 통과했습니다.

1. 코드를 제출하면 일어나는 일

① 사전 점검빈 코드이거나 빈칸 ____이 남았으면 실행하지 않고 바로 알려 줍니다.
② 문법 규칙 검사"for문을 써야 함" 같은 문제 조건을 지켰는지 코드를 읽어서 확인합니다(실행하지 않음).
③ 별도 프로그램에서 실행공개 테스트와 숨김 테스트를 모두 실행하고, 실제 결과만 돌려줍니다.
④ 채점출력, 함수가 돌려준 값, 예외 발생 여부를 기대값과 비교합니다.
⑤ 기록제출 코드, 테스트별 결과, 틀린 이유를 저장하고 오답 노트를 갱신합니다.

점선 상자만 별도 프로그램(프로세스)에서 일어납니다. 나머지는 앱 안에서 처리되지만 사용자 코드를 실행하지는 않습니다.

2. 실수해도 앱이 멈추지 않습니다

이런 코드를 실행하면엔진의 대응검증
while True: pass (무한 루프)5초 뒤 강제로 끝내고 "시간 초과"로 알려 줍니다통과
time.sleep(30)같은 방식으로 끝냅니다통과
끝없이 print2만 자에서 끊고 "출력 초과"로 알려 줍니다. try/except로 감싸도 피할 수 없습니다통과
print(1/0)"0으로 나누기" 오류와 문제가 생긴 줄 번호를 보여 줍니다통과
괄호·콜론 빠뜨림"문법 오류"와 줄 번호를 보여 줍니다통과
input()을 입력보다 많이 호출"입력 부족"으로 알려 줍니다통과
os._exit()로 강제 종료"비정상 종료"로 처리합니다통과

한계: 별도 프로그램 실행은 앱이 멈추지 않게 지켜 주지만 완전한 보안 장치는 아닙니다. 내 PC에서 내가 쓴 코드만 실행하는 용도입니다.

3. 학습 규칙

수업 완료

그날 필수 문제를 모두 통과하고 정리 퀴즈를 제출해야 완료됩니다. 처음 주어진 코드 그대로 내거나 예시만 맞추면 완료되지 않습니다.

다음 수업 열림

이전 Day를 완료해야 다음 Day가 열립니다. 완료한 수업은 나중에 틀려도 완료 상태가 유지됩니다.

힌트와 정답

힌트는 한 단계씩 열립니다. 정답은 한 번 이상 제출해 본 뒤에 볼 수 있고, 봤다는 기록이 남습니다.

오답 노트

틀린 문제는 자동으로 기록되고 틀린 횟수가 쌓입니다. 나중에 맞히면 "해결됨"으로 바뀝니다.

연속 학습

문제 제출이나 퀴즈를 한 날만 학습일로 셉니다. 오늘 아직 공부하지 않았어도 어제까지의 연속 기록은 유지됩니다.

기록 유지

앱을 껐다 켜도 진도, 작성 중이던 코드, 제출 기록이 그대로 남는 것을 확인했습니다.
