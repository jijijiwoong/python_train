01단계 · 설계 요약

상태: 완료 · 2026-10-16
앱을 실제로 만들기 전에 설계도를 그린 단계입니다. 앱을 다섯 부분으로 나눴습니다. 화면, 코드를 실행하고 채점하는 엔진, 수업 내용 파일, 학습 기록 저장소, 나중에 AI를 붙일 자리입니다. 각 부분이 무엇을 맡는지 정했고, 학습 기록을 어떤 표에 저장할지, 수업과 문제를 어떤 형식의 파일로 쓸지도 정했습니다. 가장 중요한 결정은 내가 쓴 코드를 앱과 다른 별도 프로그램(프로세스)에서 실행한다는 것입니다. 이렇게 하면 무한 루프 같은 실수를 해도 앱이 멈추지 않습니다. 또 문제를 실제로 풀어야만 수업이 "완료"됩니다. 설계한 저장소 구조와 예시 수업 파일은 실제로 실행해 검증했습니다.

1. 앱의 구조

화면 (Streamlit)

사용자가 보는 웹 화면입니다. 왼쪽 사이드바로 다섯 화면을 오갑니다. 화면은 그리기만 하고 계산은 엔진에 맡깁니다.

코드 실행기 (별도 프로세스)

사용자 코드는 여기서만 실행됩니다. 5초가 넘으면 강제로 끝내고, 출력이 너무 많으면 자릅니다. 앱 본체는 영향을 받지 않습니다.

▲ 결과 · 엔진 ↔ 아래 두 저장소

수업 내용 파일 (JSON) · 학습 기록 (SQLite) · AI 연결 자리

수업과 문제는 파일로 따로 관리하므로 코드를 고치지 않고 Day를 추가할 수 있습니다. 학습 기록은 PC 안의 데이터베이스 파일에 저장되어 앱을 껐다 켜도 남습니다. AI 연결 자리는 지금은 비워 둡니다.

4. 채점은 이렇게 합니다

빈칸이 남았나?→ 필요한 문법을 썼나? (예: for문)→ 공개 테스트 실행→ 숨김 테스트 실행→ 결과 + 오류 종류 저장
용어쉬운 설명
공개 테스트문제에 보이는 예시입니다. 무엇을 넣었고 무엇이 나와야 하는지 모두 보여 줍니다.
숨김 테스트내용은 숨기고 "몇 개 통과"만 알려 줍니다. 예시만 맞추는 꼼수를 막고 경계값(0, 음수 등)을 확인합니다.
힌트2~3단계로 하나씩 열립니다. 정답 코드는 들어 있지 않습니다.
정답 보기한 번 이상 제출해 본 뒤에만 열립니다. 정답을 본 뒤에 풀어도 완료로 인정하지만 기록에 표시가 남습니다.
수업 완료그날의 필수 문제를 모두 통과하고 정리 퀴즈를 제출해야 완료됩니다. 다음 Day는 그 뒤에 열립니다.

5. 학습 기록 저장소 (표 8개)

표 이름무엇을 저장하나어디에 쓰이나
lesson_progressDay별 진행 상태(시작 전 / 진행 중 / 완료)진행률, 이어하기
submissions제출한 코드와 채점 결과정답률, 기록
test_results제출마다 테스트 하나하나의 결과채점 결과 화면
exercise_state문제별 상태, 작성 중인 코드, 연 힌트 수이어서 풀기
wrong_notes틀린 문제, 틀린 횟수, 해결 여부오답 노트, 복습 추천
quiz_answers복습·정리 퀴즈 답수업 완료 조건
activity_log공부한 활동과 날짜학습 일수, 연속 학습
settings앱 설정나중에 확장

틀린 이유는 21가지로 나눠 기록합니다(문법 오류, 들여쓰기 오류, 오답, 시간 초과 등). 그래서 "내가 자주 하는 실수"를 통계로 볼 수 있습니다.

6. 검증 결과

  • 저장소 설계(schema.sql)를 실제 SQLite에 적용했습니다. 표 8개가 만들어졌고, 잘못된 값이 들어가지 않도록 막는 규칙이 동작했습니다.
  • 예시 수업 파일(Day 6)이 다섯 칸 순서, 합계 15분, 문제 연결 규칙을 지킵니다.
  • 예시 문제의 모범 답안은 모든 테스트를 통과하고, 처음 주어지는 코드는 통과하지 못합니다. 즉, 풀지 않고는 완료할 수 없습니다.
  • 설명 속 예제 코드 2개를 실제로 실행했고, 적어 둔 출력과 같았습니다.

7. 확인이 필요한 점

Python 버전: PC에 설치된 버전은 3.14.6입니다. 화면 도구(Streamlit)가 이 버전에서 잘 동작하는지 설치 단계에서 확인합니다.
보안 범위: 별도 프로세스 실행은 앱이 멈추는 것은 막아 주지만 완전한 보안 장치는 아닙니다. 그래서 내 PC에서 내가 쓴 코드만 실행하는 용도로 제한합니다.
숨김 테스트: 수업 파일을 직접 열면 숨김 테스트 내용이 보입니다. 개인 학습용이라 허용했습니다.
