# Python Learning Lab

매일 15분씩 Python을 공부하기 위해 만든 개인용 로컬 학습 앱입니다.

Python 기초부터 심화 문법, 데이터 분석, 머신러닝, PyTorch 딥러닝까지 순서대로 공부할 수 있도록 구성했습니다.

단순히 강의를 읽는 방식이 아니라 직접 코드를 작성하고 실행하면서 개념을 익히고, 자동 채점을 통해 이해도를 확인할 수 있습니다.

현재 Day 1~14까지 구현했으며, 최종 목표는 168일(24주) 과정입니다.

## 1. 학습 구성

하루 학습 시간은 약 15분입니다.

| 단계 | 시간 | 내용 |
|---|---|---|
| 복습 | 2분 | 이전에 배운 내용 확인 |
| 핵심 개념 | 4분 | 새로운 Python 개념 학습 |
| 빈칸 채우기 | 3분 | 코드의 빈칸을 직접 채우며 연습 |
| 직접 작성 | 4분 | 배운 개념을 활용해 코드 작성 |
| 정리 및 점검 | 2분 | 퀴즈를 풀고 이해도 확인 |

앱은 대시보드, 오늘의 수업, 코드 실습, 오답 노트, 학습 기록으로 구성되어 있습니다.

현재 학습 가능한 범위는 다음과 같습니다.

- 1주차: Python 기초 문법
- 2주차: 리스트와 튜플
- Day 7, 14: 누적 복습

사용 기술은 Python 3.12 이상, Streamlit, SQLite, JSON, pytest입니다.

## 2. 설치 방법

처음 사용할 때 한 번만 설치하면 됩니다.

Windows PowerShell을 열고 아래 명령어를 순서대로 실행합니다.

먼저 프로젝트 폴더로 이동합니다.

```powershell
cd C:\Users\jiwoo\python_train
```

가상환경을 생성합니다.

```powershell
python -m venv .venv
```

필요한 라이브러리를 설치합니다.

```powershell
.venv\Scripts\python -m pip install -r requirements.txt
```

Python은 3.12 이상이 필요합니다. 현재 개발 및 테스트에 사용한 버전은 Python 3.14.6입니다.

`.venv`는 이 프로젝트에서만 사용하는 가상환경이므로 다른 Python 프로젝트에는 영향을 주지 않습니다.

## 3. 앱 실행 방법

PowerShell에서 프로젝트 폴더로 이동한 뒤 아래 명령어를 실행합니다.

```powershell
.\run_app.cmd
```

또는 파일 탐색기에서 `run_app.cmd`를 더블클릭해도 됩니다.

앱이 실행되면 브라우저에서 다음 주소가 열립니다.

http://localhost:8501

앱을 종료하려면 실행 창에서 `Ctrl + C`를 누르거나 창을 닫으면 됩니다.

직접 Streamlit 명령어로 실행하고 싶다면 아래 명령어를 사용합니다.

```powershell
.venv\Scripts\python -m streamlit run lab_app\app.py --server.address localhost --server.headless true --browser.gatherUsageStats false
```

현재 앱은 로컬 실행을 기준으로 만들어져 있으므로 `--server.address localhost` 옵션을 반드시 넣어야 합니다.

## 4. 앱 사용 방법

### 수업 진행

1. 대시보드에서 오늘 공부할 내용을 확인합니다.
2. 학습 시작 버튼을 눌러 수업에 들어갑니다.
3. 각 단계에서 개념을 공부하고 문제를 풉니다.
4. 필수 문제를 모두 통과하고 정리 퀴즈를 제출하면 해당 Day가 완료됩니다.
5. 완료 후 다음 Day를 학습할 수 있습니다.

학습 중에는 위쪽 단계 버튼이나 아래의 다음 단계 버튼을 통해 이동할 수 있습니다.

중간에 앱을 종료해도 마지막으로 공부하던 위치가 저장되어 이어서 학습할 수 있습니다.

### 코드 실습 기능

| 기능 | 설명 |
|---|---|
| ▶ 실행 | 작성한 코드를 채점 없이 실행 |
| ✔ 채점 | 공개 테스트와 숨김 테스트로 정답 확인 |
| 💡 힌트 | 문제 해결을 위한 힌트를 단계별로 제공 |
| 📖 모범 답안 | 채점 후 모범 답안 확인 |
| ↺ 처음 코드로 | 작성한 코드를 시작 상태로 초기화 |

`input()`이 필요한 문제는 실행할 때 넣을 입력값에 값을 한 줄씩 작성하면 됩니다.

모범 답안은 최소 한 번 채점한 뒤 확인할 수 있으며, 답안을 열어본 기록도 저장됩니다.

수업을 읽기만 하거나 시간이 지났다고 자동으로 완료되지는 않습니다. 필수 문제와 정리 퀴즈를 끝내야 다음 수업으로 넘어갈 수 있습니다.

### 오답 노트 및 학습 기록

틀린 문제는 오답 노트에 자동으로 저장됩니다.

오답 노트에서는 틀린 문제를 확인하고, 메모를 남기거나 다시 풀어볼 수 있습니다.

학습 기록에서는 날짜별 학습 이력과 개념별 성취도를 확인할 수 있습니다. 이어하기 기능으로 이전에 공부하던 위치로 돌아갈 수도 있습니다.

코드 실습 메뉴의 자유 실습에서는 채점이나 학습 기록 없이 원하는 Python 코드를 실행할 수 있습니다.

참고로 코드 실행에는 5초 제한이 있으며, 출력은 최대 20,000자까지 표시됩니다. 무한 루프가 발생하면 실행을 자동으로 중단합니다.

학습일과 연속 학습일은 문제를 제출하거나 퀴즈를 푼 날을 기준으로 계산합니다.

## 5. 테스트 방법

앱이 정상적으로 작동하는지 확인하려면 프로젝트 폴더에서 아래 명령어를 실행합니다.

```powershell
.venv\Scripts\python -m pytest
```

현재 총 173개의 테스트가 있으며, 전체 실행에는 약 1분이 걸립니다.

테스트에서는 다음 항목을 확인합니다.

- 앱의 주요 기능이 정상 작동하는지
- 문제의 모범 답안이 실제로 정답 처리되는지
- 시작 코드가 잘못 정답 처리되지 않는지
- 예제 코드의 출력 결과가 맞는지
- 수업 구성이 정해진 형식과 시간에 맞는지
- 힌트에 정답 코드가 노출되지 않는지
- 학습 기록 및 진도 관리가 정상적으로 작동하는지

테스트는 별도의 임시 데이터베이스를 사용하므로 실제 학습 기록에는 영향을 주지 않습니다.

테스트 커버리지도 확인할 수 있습니다.

```powershell
.venv\Scripts\python -m pytest --cov=lab_app
```

## 6. 폴더 구조

현재 프로젝트는 개발 기록과 실제 앱 코드를 분리했습니다.

```text
python_train/
├── README.md
├── run_app.cmd
├── requirements.txt
├── pyproject.toml
├── index.html
│
├── 01_design/
├── 02_.../
├── ...
├── 06_release/
│
└── lab_app/
    ├── app.py
    ├── components.py
    ├── config.py
    ├── views/
    ├── core/
    ├── llm/
    ├── content/
    │   ├── curriculum.json
    │   └── lessons/
    │       ├── day01.json
    │       ├── ...
    │       └── day14.json
    ├── data/
    │   └── learning.db
    └── tests/
```

각 폴더의 역할은 다음과 같습니다.

| 폴더 및 파일 | 역할 |
|---|---|
| `01_design/ ~ 06_release/` | 개발 단계별 작업 기록 및 결과 정리 |
| `index.html` | 개발 진행 현황 확인 |
| `lab_app/app.py` | 앱 실행 및 화면 이동 |
| `lab_app/components.py` | 코드 에디터, 채점 결과 등 공통 기능 |
| `lab_app/views/` | 대시보드, 수업 등 5개 화면 |
| `lab_app/core/` | 코드 실행, 자동 채점, 진도 관리, DB 처리 |
| `lab_app/content/` | 커리큘럼 및 수업 JSON 파일 |
| `lab_app/llm/` | 추후 AI 피드백 기능을 연결할 공간 |
| `lab_app/data/` | 개인 학습 기록 저장 |
| `lab_app/tests/` | 기능 및 콘텐츠 검증 테스트 |

개발 단계 폴더에는 `CLAUDE.md`와 `summary.html` 등을 통해 작업 내용을 기록하고, 실제 실행 코드는 `lab_app/`에서 관리합니다.

## 7. 학습 기록 관리

학습 기록은 SQLite 데이터베이스에 저장됩니다.

```text
lab_app\data\learning.db
```

앱을 종료하더라도 학습 진도와 문제 풀이 기록은 유지됩니다.

### 학습 기록 백업

앱을 종료한 뒤 다음 명령어를 실행합니다.

```powershell
Copy-Item lab_app\data\learning.db "learning_backup_$(Get-Date -Format yyyyMMdd).db"
```

실행 날짜를 파일명으로 사용하는 백업 파일이 만들어집니다.

### 처음부터 다시 시작하기

앱을 종료한 뒤 `learning.db` 파일을 다른 이름으로 변경하면 됩니다.

다음 실행 시 새로운 데이터베이스가 생성되어 처음부터 학습할 수 있습니다.

기존 기록이 필요할 수 있으므로 초기화하기 전에 백업하는 것을 권장합니다.

다른 위치에 데이터베이스를 저장하고 싶다면 실행 전에 환경변수를 설정할 수도 있습니다.

```powershell
$env:LAB_DB_PATH = "D:\경로\learning.db"
```

## 8. 새로운 수업 추가하기

현재는 Day 1~14까지만 구현되어 있습니다.

Day 15부터는 JSON 파일을 추가하는 방식으로 수업을 확장할 수 있습니다.

예를 들어 Day 15를 만들려면 다음 파일을 생성합니다.

```text
lab_app\content\lessons\day15.json
```

기존 `day01.json`부터 `day14.json`까지의 파일을 참고하면 됩니다.

수업 데이터 형식은 아래 문서에 정리되어 있습니다.

```text
01_design\content_schema.md
```

새 수업 파일을 만든 뒤에는 `lab_app\content\curriculum.json`에도 해당 Day를 추가해야 합니다.

7의 배수에 해당하는 Day는 누적 복습일이므로 `"is_review": true`로 설정합니다.

수업을 추가한 다음에는 아래 명령어로 검사합니다.

```powershell
.venv\Scripts\python -m pytest lab_app\tests\test_real_content.py
```

참고로 `test_weeks_one_and_two_are_complete_and_clean` 테스트는 현재 Day 1~14를 기준으로 작성되어 있습니다.

Day 15 이후의 콘텐츠를 추가할 때는 이 테스트의 Day 목록과 복습일 목록도 함께 수정해야 합니다.

## 9. 자주 발생하는 오류

| 오류 및 증상 | 해결 방법 |
|---|---|
| `No module named pytest` | 프로젝트 폴더에서 가상환경 Python으로 실행했는지 확인 |
| `No module named streamlit` | 프로젝트 폴더 이동 후 라이브러리 재설치 |
| `.venv 가상환경이 없습니다` | 설치 단계에서 가상환경 생성 |
| `OSError: Long Path` | 프로젝트 경로를 짧게 바꾸거나 Windows 긴 경로 사용 활성화 |
| 이 PC에서만 실행할 수 있다는 안내 | `--server.address localhost` 옵션 확인 |
| `Port 8501 is already in use` | 기존 앱 실행 창 종료 또는 브라우저에서 기존 주소 접속 |
| 수업 JSON 오류 | 화면에 표시된 파일과 오류 위치 확인 후 수정 |
| 수정한 코드가 채점에 반영되지 않음 | 코드 에디터 밖을 클릭한 뒤 다시 채점 |
