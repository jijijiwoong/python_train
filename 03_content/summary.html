첫 주(Day 1~7) 수업을 만들었습니다. 매일 15분 동안 복습 → 개념 설명 → 빈칸 채우기 → 직접 작성 → 정리 순서로 진행됩니다. 설명은 모두 한국어이고, 개념 설명 속 예제 코드는 실제로 실행해 화면에 적힌 결과가 나오는 것을 확인했습니다. 문제는 모두 15개입니다. 각 문제의 모범 답안은 자동 채점을 통과하고, 처음 주어지는 코드는 통과하지 못하는 것도 확인했습니다. 초보자가 자주 하는 실수 10가지가 알맞은 오류로 채점되는지도 테스트했습니다. 수업 내용은 코드와 분리된 파일이라 Day 8부터는 파일만 추가하면 됩니다.
