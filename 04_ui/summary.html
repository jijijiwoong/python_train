4. 검증 중 찾아서 고친 문제

무엇이 문제였나어떻게 고쳤나
보안 같은 네트워크의 다른 기기에서도 앱에 접속해 코드를 실행할 수 있었음이 PC(localhost)에서만 열리게 실행하고, 다른 방식으로 켜지면 앱이 화면을 막고 안내합니다
페이지 주소로 바로 들어가면 메뉴와 보안 검사가 빠진 화면이 열림화면 폴더 이름을 pages → views로 변경 (확인 후 진행)
한국어 문장에서 굵은 글씨가 ** 기호 그대로 보임수업 파일을 고치고, 같은 실수를 자동으로 찾아내는 검사를 추가
퀴즈 오답 안내가 한 줄에 섞여 읽기 어려움결과 / 정답 / 해설을 나눠 표시
숨김 테스트가 없는 문제에 "숨김 0/0" 표시숨김 테스트가 있을 때만 표시
무한 루프로 멈추면 그 전에 출력한 내용도 사라짐멈추기 전까지의 출력을 보여 주도록 개선 (자동 테스트 추가)

5. 앱 실행 방법

프로젝트 폴더에서 run_app.cmd를 더블클릭하거나, PowerShell에서 아래처럼 실행합니다. 몇 초 뒤 브라우저가 자동으로 열립니다(http://localhost:8501).

.\run_app.cmd

자세한 설치 방법과 README는 06단계에서 정리합니다. 자동 테스트는 107개 모두 통과합니다.

6. 확인이 필요한 점

화면 자동 테스트 없음: 화면은 브라우저로 직접 확인했습니다. 화면용 자동 테스트는 05단계에서 추가를 검토합니다.
에디터 자동 들여쓰기: 빠른 자동 입력에서는 while True: 다음 줄이 들여쓰기되지 않았습니다. 직접 타이핑할 때의 동작을 06단계에서 확인합니다.
